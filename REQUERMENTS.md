# Системные требования

Ubuntu (CPU-only):

```bash
sudo apt update
sudo apt install ffmpeg python3 python3-dev build-essential
```

Python зависимости проекта устанавливаются через `uv sync`. Нужен `uv` (устанавливается отдельно по официальной инструкции Astral). CUDA/GPU не требуется. OpenCV используется в headless-режиме; GUI-пакеты не нужны.

ONNX-модель детекции курения включена в `models/`; дополнительный APT-пакет или PyTorch устанавливать не нужно.

Для практической скорости около 0.5x и выше рекомендуется современный многоядерный CPU. Фактическая скорость зависит от разрешения/кодека ролика и CPU. Анализ идёт с частотой `analysis.sample_fps`; кодирование использует preset `veryfast`. Время обработки показывается отдельно для анализа и сборки в TQDM.
